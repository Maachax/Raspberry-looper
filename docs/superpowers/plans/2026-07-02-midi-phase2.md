# MIDI Control Phase 2 (Modal Layer) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Everything the web UI can do becomes controllable from the MPK: SECTION_EDIT and FX_EDIT modes, a loop-selection cursor on the keybed, contextual knobs for effect parameters, create/save/mute/delete on bank-B pads, with the web UI as glance-only display (mode banner + selection highlights).

**Architecture:** Extends Phase 1's `MidiController`: mode state machine (`play`/`section_edit`/`fx_edit`), selection state (`selected_loop`, `selected_fx_slot`, `editing_section`), a shared `select` binding map consulted in play+fx_edit, double-tap confirm for destructive actions, and an idle-commit buffer for FX-param knobs (because `set_loop_chain` re-bakes the wet buffer under the looper lock — never per CC tick). UI reads it all from the `midi` block in `get_state()`.

**Tech Stack:** Python 3.13 (`./bin/python`), existing mido stack, pytest, existing Flask-SocketIO app.

## Global Constraints

- Spec: `docs/superpowers/specs/2026-07-02-midi-control-design.md` (Phase 2 = "the modal layer").
- **Audio-safety:** `WebLooper.set_loop_chain` re-bakes while holding `looper.lock` — call it only on discrete presses (add/toggle/remove) or after a 300 ms knob-idle commit, never per CC tick. `set_bus` is cheap (no bake) and may be called per tick.
- Measured triggers: keybed = notes 48–72 ch 0 (mido 0-based); bank-B pads = PC ch 9, top row 12,13,14,15, bottom row 8,9,10,11 (reading order); knobs = CC ch 0 numbers 70–77.
- Double-tap confirm window: 1 s. Learn timeout stays 10 s. Notify debounce stays ≤10/s.
- Effect types in key order 60–64: `reverb`, `delay`, `chorus`, `distortion`, `filter` (from `effects.EFFECT_SCHEMAS`; ≤3 params each; `filter.mode` is enum `['LP','HP']`).
- Existing looper API (verified): `layers` (list, `layer.id` == index, `.is_playing`, `.fx_chain`, `.name`), `toggle_layer(idx)`, `delete_layer(idx)` (refuses idx 0), `add_section() -> {'id',...}`, `set_section_loops(id, loop_ids)`, `delete_section(id)`, `active_section_id`, `save_session(name)` ('' → timestamp name), `set_loop_chain(idx, chain)`, `set_bus(None, effect)`, `master_bus`.
- Run tests with `./bin/python -m pytest` from `/home/max/looper`. Current suite: 82 passing.

        """Double-tap guard: True only on the second tap within 1s."""
        now = time.monotonic()
        if (self._confirm and self._confirm[0] == action

def scale_param(param, cc_value):
    """Map a 0-127 CC value into a schema param's range (numeric or enum)."""
    if 'options' in param:
        options = param['options']
        return options[min(len(options) - 1, cc_value * len(options) // 128)]
    return param['min'] + (param['max'] - param['min']) * cc_value / 127.0

    # ------------------------------------------------------------ fx knobs
    def _edit_param(self, param_index, cc_value):
        """Buffer a param edit; commit after 0.3s idle (set_loop_chain re-bakes
        under looper.lock, so it must never run per CC tick)."""
        if self._param_pending is None:
            idx, chain = self._fx_chain()
            if idx is None or self.selected_fx_slot >= len(chain):
                return
            self._param_pending = (idx, chain)
        idx, chain = self._param_pending
        if self.selected_fx_slot >= len(chain):
            return
        effect = chain[self.selected_fx_slot]
        schema = EFFECT_SCHEMAS.get(effect['type'], [])
        if param_index >= len(schema):
            return
        param = schema[param_index]
        effect['params'][param['name']] = scale_param(param, cc_value)
        if self._param_timer is not None:
            self._param_timer.cancel()
        self._param_timer = threading.Timer(0.3, self.flush_params)
        self._param_timer.daemon = True
        self._param_timer.start()

    def flush_params(self):
        """Commit the buffered param edit (one bake), if any."""
        if self._param_timer is not None:
            self._param_timer.cancel()
            self._param_timer = None
        if self._param_pending is not None:
            idx, chain = self._param_pending
            self._param_pending = None
            self.looper.set_loop_chain(idx, chain)
            self._notify_debounced()

    def _edit_bus(self, param_name, cc_value):
        effect = copy.deepcopy(self.looper.master_bus) or default_effect('reverb')
        effect['params'][param_name] = cc_value / 127.0
        self.looper.set_bus(None, effect)
