# UI Rework Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the current single-column scrollable web UI with a fixed-height DAW-style two-column layout — flat panels, accent borders, collapsible side panel — without touching any backend code.

**Architecture:** `index.html` is restructured into topbar / two-column body / footer. `style.css` is rewritten from the design tokens up. `app.js` gets a side-panel toggle and topbar state display; all existing audio/socket logic is preserved.

**Tech Stack:** Vanilla JS, CSS custom properties, SVG fretboard, Flask-served static files.

---

## File Map

| File | What changes |
|---|---|
| `templates/index.html` | Full restructure: topbar → two-col body → footer; scale section moves into side panel |
| `static/style.css` | Full rewrite of tokens + layout; component styles for panels, layers, buttons, sliders |
| `static/app.js` | Add `activeSidePanel` state + `setSidePanel()`; update `updateUI()` for topbar; gate `renderFretboard()` on panel open; update layer row HTML |

Backend files (`audio.py`, `routes.py`, `main.py`) are not touched.
