# Mobile Companion UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The web UI becomes fully phone-usable — status-display home, bottom tabs, touch-sized controls, section naming, home-screen manifest and wake lock — with the desktop layout untouched above 740px.

**Architecture:** One responsive page. A `@media (max-width: 740px)` block re-flows the existing flex document (topbar / app-body / edit-panels / bottom-bar): side strip hidden, new bottom tab bar, side panels and edit panels go fullscreen. A small backend addition gives sections a persisted `name`. No new routes, no new JS state model.

**Tech Stack:** Existing Flask-SocketIO app, vanilla JS/CSS, pytest.

## Global Constraints

- Spec: `docs/superpowers/specs/2026-07-02-mobile-ui-design.md`.
- Breakpoint: `max-width: 740px`. Desktop (>740px) must be visually unchanged — every mobile rule lives inside the media query or on mobile-only elements.
- Touch targets ≥44px on mobile.
- Known DOM/CSS facts: document is flex column `topbar / .app-body (.left-col 44% + .side-wrap[.side-strip + .side-content]) / .edit-panels (sibling, shown via body.edit-mode) / .bottom-bar`; CSS vars `--topbar-h`, `--footer-h`, palette vars in `:root`; `setSidePanel(name)` toggles panels by capitalized id; `toggleViewMode()` toggles `body.edit-mode`; trim/export/sessions live inside `#editPanels`; `openTrimEditor()` enters edit-mode and scrolls to `#trimSection`.
- Section state shape: `serverState.sections = {list, pending_id, active_id}`; section dicts currently `{id, loop_ids, fx_overrides}`.

        """Rename a section. Empty/whitespace names are refused."""
        name = (name or '').strip()
        if not name:
            return False

            if section is None:

            section['name'] = name

Add to `static/app.js` near `setSidePanel`:

```javascript
        // =================================================================
        // MOBILE NAVIGATION
        // =================================================================

        function setMobileTab(name) {
            const menu = document.getElementById('mobileMoreMenu');
            if (name === 'more') {                     // toggle the menu sheet
                menu.classList.toggle('open');
                return;
            }
            menu.classList.remove('open');
            document.querySelectorAll('.mobile-tab').forEach(b =>
                b.classList.toggle('active', b.dataset.tab === name));
            if (document.body.classList.contains('edit-mode')) toggleViewMode();
            if (name === 'home') {
                if (activeSidePanel) setSidePanel(activeSidePanel);   // toggles closed
            } else {                                   // sections | fx | scale
                if (activeSidePanel !== name) setSidePanel(name);
            }
        }

        function mobileMore(entry) {
            document.getElementById('mobileMoreMenu').classList.remove('open');
            document.querySelectorAll('.mobile-tab').forEach(b =>
                b.classList.toggle('active', b.dataset.tab === 'more'));
            if (entry === 'meters' || entry === 'midi') {
                if (document.body.classList.contains('edit-mode')) toggleViewMode();
                if (activeSidePanel !== entry) setSidePanel(entry);
                return;
            }
            // sessions / export live in the edit panels
            if (activeSidePanel) setSidePanel(activeSidePanel);       // close side panel
            if (!document.body.classList.contains('edit-mode')) toggleViewMode();
            const el = document.getElementById(entry === 'sessions' ? 'sessionNameInput' : 'exportBtn');
            if (el) el.scrollIntoView({ behavior: 'smooth', block: 'center' });
            if (entry === 'sessions') document.getElementById('sessionNameInput').focus();
        }

        function mobileSave() { mobileMore('sessions'); }
```

- [ ] **Step 3: Wake lock**

In `static/app.js`, near the initialization section (before `connect();`):

```javascript
        // =================================================================
        // SCREEN WAKE LOCK — the phone is the MPK's display; don't sleep
        // =================================================================

        let wakeLock = null;
        async function acquireWakeLock() {
            if (!('wakeLock' in navigator)) return;
            try {
                wakeLock = await navigator.wakeLock.request('screen');
            } catch (e) { /* denied (battery saver etc.) — fine */ }
        }
        document.addEventListener('pointerdown', () => acquireWakeLock(), { once: true });
        document.addEventListener('visibilitychange', () => {
            if (document.visibilityState === 'visible') acquireWakeLock();
        });
```
