# MPK Mini — Looper Cheat Sheet

Keep the keybed at the **default octave** (OCT LEDs centred) — key commands
move with octave shift. Pad positions are reading order (top-left = 1).

## Pads — Bank A (sections, every mode)
PLAY: launch section 1–8 · SECTION EDIT: pick section 1–8 to edit

## Pads — Bank B (actions, every mode)
| 1 ● Rec/Overdub | 2 Tap tempo | 3 Create section | 4 Save session |
| 5 SECTION EDIT | 6 FX EDIT | 7 Mute selected | 8 Delete selected ✕✕ |

(✕✕ = tap twice within 1 s)

## Keys — lower octave (C to B)
PLAY / FX EDIT: select loop 1–12 · SECTION EDIT: toggle loop 1–12 in section

## Keys — upper octave (FX EDIT)
| C | C# | D | D# | E | F | F#| G | G#| A | A#| B | C |
| +rev | +dly | +cho | +dst | +flt | ◀ slot | – | slot ▶ | – | on/off | – | remove ✕✕ | EXIT |

SECTION EDIT: B = delete section ✕✕ · top C = EXIT (top C exits any mode)

## Knobs
PLAY / SECTION EDIT: K1–K8 = loop 1–8 volume
FX EDIT: K1–K3 = selected effect params (schema order) · K7 = bus room · K8 = bus wet

## Screen tells you
Orange banner = SECTION EDIT (+ which section) · Purple = FX EDIT
(+ loop · effect) · outlined loop row = selection · "tap again" = confirm armed
